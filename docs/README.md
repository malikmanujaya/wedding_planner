## How to work with Cursor

1. Freeze packages in v1 (`S0-01`).
2. Track work by task ID (`A-11`, `B-03`, …).
3. Say in chat: `start A-11` / `done B-03` to sync status.
4. Client blockers (`B-30` WA, `C-22` PayHere) start in week 1.

## Lean path (budget-tight)

Ship **S0 + Package A + Package B** first. Defer C (public/gifts), D (marketplace), E (mobile).
